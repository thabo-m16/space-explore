# space-explore
A space exploration site is a NASA inspired site

Underneath are notes:
Using this site for clean images: https://unsplash.com/
How to insert a background image using css: background-image: url("images/universe.jpg");
And resizing the background image to fit the browser: background-size: cover;
Buttons do not inherit fonts but if you want them to; use the "font-family: inherit".
Using google fonts to get more fun fonts to use or 10001fonts.com.
Another method of using fonts:
@font-face{
    src url("file.tff");<!--file font that is downloaded from one of these sites-->
    font-family: file; <!--using the files name or any name as a font-->
}
h1{
   font-family: file; <!--this assigns the font-->
}

ODEAL:
Confusing the difference between centering content using display and margin auto elements than using text-align.
1. text-align centers a group of elements
2. The first route centers a specific element.
3. display block: A block element takes up the full available width of its parent by default and starts on a new line.
4. display inline: An inline element doesn't start a new line.
